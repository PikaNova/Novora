# 「分考试编辑器」整页改大弹窗：方案（2026-09-24 提出，待拍板，未动代码）

> 口径更正：第一版方案写成了「单个科目的表单改弹窗」，理解错了。本文按用户澄清重写——
> 指的是**编辑考试那一整页**（左栏考试卡 + 右侧分考试列表，即 `/admin/exam/editor`）改成一个大型弹窗。

## 一、现状

这一页就是用户贴出来的那个界面：

```
左栏（aside.admin-sidebar）                     主区（main.admin-main）
┌───────────────────────────────┐   ┌──────────────────────────────────────────┐
│ 高一 · 大型考试      共 10 场   │   │ 444 · 考试安排                0 项        │
│ 444                           │   │ [AI智能导入考试]                          │
│ 0 个分考试 · 0 个启用          │   │ 当前大型考试暂无分考试，点击左侧…          │
│ [设置] [删除]                  │   │                                          │
│ 切换年级只改变后台管理内容…     │   │                                          │
│ [ + 添加分考试 ] [批量添加分考试]│   │                                          │
│ 使用说明（四条）                │   │                                          │
└───────────────────────────────┘   └──────────────────────────────────────────┘
```

- 渲染组件：`src/components/major/MajorTabPanel.tsx`（`aside.admin-sidebar` + `main.admin-main`，47 个 props）。
- 它是一个**独立视图**：`EXAM_CENTER_VIEWS = ['current','schedule','history','weekly','editor']`
  （`src/hooks/admin/adminRoutes.ts:42`），路由 `/admin/exam/editor`，可深链、**不进左栏导航**。
- 谁来打开它（现在都是**换页**）：
  1. 考试中心列表行的「编辑考试」→ `openExamRecordEditor()`（`AdminPage.tsx:859`）
  2. 日程轴 / 班级网格行的「编辑」→ 同一个 `openExamRecordEditor`
  3. 「当前考试」面板 → `editExamFromCurrent`
  4. 新建/编辑向导第 2 步：「+ 添加科目（打开编辑器）」「改时间」「去编辑器逐项调整」→ `openMajorEditor`（`AdminPage.tsx:718`）
- 这一页里还会再打开一批弹窗：批量添加（`MajorBatchAddModal`）、AI 导入（`AiImportModal`）、
  时间选择器（`TimeRangePickerModal`）、打印预览（`SchedulePrintPreview`）、确认对话框、
  快捷考试相关弹窗——**层级最深会到第 3~4 层**。
- 已有可直接复用的弹窗基建：`AdminModalPortal`、`.admin-modal-overlay` / `.admin-modal` /
  `--wide` / `--workflow`、`useBackdropDismiss`（点遮罩关闭）、详情抽屉已把宽度放开到
  `min(1120px, 100vw - 48px)`、移动端规则在 `src/styles/admin.css:1215+`。

### 现在的问题

1. **换页丢上下文**：从日程轴上点「编辑」，跳到编辑器页；关掉之后回到列表，筛选/滚动位置都要重找。
2. **向导断链**：向导第 2 步只能跳页去改科目，回来后还要靠页面顶部那条「科目还没填完」的提示才能回到「下一步」。
3. 编辑器两栏本来就宽（左栏固定 + 主区列表），整页形态在 1440px 下是合适的，但**没法叠在正在看的内容上**。

## 二、目标

把这一页整体装进一个**大型弹窗**：从考试中心或向导打开它，关掉就回到原处；内容、动作、权限都不变，
只换呈现形态。不改数据模型、不改保存链路（仍走 `commitItems` → 自动保存 → 云同步 / 离线 outbox）。

## 三、方案

### A（推荐）：弹窗壳 + 原样内嵌现有面板

新增 `src/components/major/MajorEditorModal.tsx`，内部**原样渲染** `MajorTabPanel`（47 个 props 一个不改），
弹窗负责：尺寸、滚动、关闭/回程、Esc/遮罩、层级。

- 尺寸：新增样式档 `admin-modal--editor` → `width: min(1180px, 100vw - 48px)`、
  `height: min(92vh, 880px)`；**左右各自滚动**（左栏 `overflow:auto`，主区列表 `overflow:auto`），
  不给整窗加长滚动条。
- 头部：标题「编辑考试 · {考试名}」+ 右上角关闭；底部不放统一操作条（编辑即自动保存），
  但保留明显的「完成」按钮，和 Esc / 点遮罩等价。
- 关闭：`Esc` / 点遮罩（`useBackdropDismiss`）/ 右上角 ×，三者等价；若科目表单正在编辑且有改动，
  走一次 `confirmDialog` 二次确认。
- 回程：关闭后回到**打开它的那个视图**（列表 / 日程 / 当前考试 / 向导第 2 步），筛选与滚动位置保留。

**入口改造**：`openExamRecordEditor` / `editExamFromCurrent` / `openMajorEditor` 一律从"切视图"改成
"打开弹窗"。

**路由**：保留 `/admin/exam/editor` 作为整页兜底（直接用这个地址打开、或刷新时仍然给整页），
交互路径不再往这里跳。是否进一步改成 `?edit=<majorId>` 深链到弹窗，见「待拍板 1」。

### B（最小）：只把向导那条路弹窗化

考试中心里点「编辑考试」仍然整页跳转，只有向导第 2 步改成弹窗。

- 好处：改动面最小（只动向导接线 + 弹窗壳），一天内可上。
- 代价：同一功能两种形态，用户从日程轴点编辑还是会被换页；"丢上下文"这个主要痛点没解决。

### C（不推荐）：把整页做成"抽屉"而不是弹窗

从右侧滑出的宽抽屉（类似现在的考试详情抽屉）。视觉上更连续，但编辑器是两栏布局，
抽屉宽度受限（1120px 已是上限），列表会更挤；且和考试详情抽屉形态重名容易混。

## 四、对比与推荐

| 维度 | B 只改向导 | A 推荐（整页→弹窗） | C 抽屉 |
|---|---|---|---|
| 解决「换页丢上下文」 | ❌ | ✅ | ✅ |
| 解决「向导断链」 | ✅ | ✅ | ✅ |
| 两栏空间 | — | ✅ 1180px 够用 | ➖ 偏挤 |
| 改动面 | 小（向导 + 壳） | 中（三个入口 + 壳 + 样式） | 中 |
| 风险 | 低 | 中（嵌套弹窗层级 / 移动端 / 回程状态） | 中高（形态容易和详情抽屉混） |

**推荐 A。** 如果只想先看到效果，可以先落 B 的壳（`MajorEditorModal` 一次写好），
先接向导，再把考试中心的三个入口切过去——壳不用重写。

## 五、需要特别处理的四件事

1. **嵌套层级**：编辑器弹窗之上还要开批量添加 / AI 导入 / 时间选择器 / 打印预览 / 确认框。
   这些组件都走 `AdminModalPortal`（挂到 `body`），按 DOM 顺序天然叠在上面；
   要确认 z-index 一致（现为 9999）时**后插入的在上**，并且 `Esc` 只关最上面那一层。
   周测侧的 `ItemFormModal`（弹窗里再开时间选择器）就是这个模式，照抄它的处理。
2. **移动端**：`< 720px` 时弹窗整屏，左栏改成一屏内可折叠的区块（或降级成「先选考试 → 再编辑科目」两步）。
   需要一次 390px 实测（横向不溢出、能滚到底）。
3. **回程状态**：从日程轴第 3 行点进来的，关掉必须回到日程轴且**保持当天/筛选**，不能回到列表首行。
   实现上把「来源视图 + 筛选」记在打开时的调用点，关闭时恢复，而不是硬编码某个视图。
4. **兜底页**：`/admin/exam/editor` 直接访问仍然要给完整页面（刷新、分享链接、老书签），
   所以 `MajorTabPanel` 本身不删、不改，弹窗只是它的第二个容器。

## 六、改动清单（按 A）

- 新增 `src/components/major/MajorEditorModal.tsx`（壳：尺寸、滚动、关闭/回程、Esc/遮罩、标题）
- `src/pages/AdminPage.tsx`：
  - `openExamRecordEditor` / `editExamFromCurrent` / `openMajorEditor` 改为打开弹窗（记录来源视图）
  - `examViewActive === 'editor'` 那条整页渲染保留（兜底），但交互不再往那跳
- `src/styles/admin.css`：新增 `admin-modal--editor`（1180×92vh）、弹窗内左栏/主区独立滚动、
  移动端整屏规则
- `src/components/admin/MajorModalWizard.tsx`：第 2 步三个入口改为开弹窗（文案不变）
- 测试：组件测试（打开/关闭回程、Esc 只关最上层、向导第 2 步进入后返回第 2 步）+
  dev 站真机验收（1440px 两栏、390px 单栏）

## 七、验收标准

- 考试中心列表 / 日程轴 / 当前考试三处点「编辑考试」→ 大弹窗打开，内容与现在的编辑器页一致；
  关闭后回到**原来的板块**，筛选和滚动位置不变。
- 向导第 2 步点「+ 添加科目」「改时间」「去编辑器逐项调整」→ 同一个弹窗叠在向导之上；
  关闭后停在向导第 2 步，「下一步」仍然可用。
- 弹窗内所有既有动作照旧：列表行编辑/停用/删除、批量添加、AI 导入、预览与导出 PDF、
  撤销删除、设置改名、删除考试、临时统一考试的延长/结束/转正式。
- 嵌套弹窗：批量添加/时间选择器/打印预览打开时，`Esc` 先关它们、再关编辑器。
- 移动端 390px：整屏、无横向溢出、底部内容可滚到。
- 直接访问 `/admin/exam/editor` 仍是完整页面（兜底不变）。
- `npm test` 通过；dev 站真机点一遍（含一次从日程轴进入→关闭的回程确认）。

## 八、待拍板

1. **路由**：`/admin/exam/editor` 保留整页兜底（推荐），还是彻底弹窗化（改成 `?edit=<majorId>` 深链、
   刷新后自动重开弹窗）？
2. **向导进入时**：叠两层（向导 + 编辑器弹窗，关掉回第 2 步，推荐），还是暂存向导、只显示编辑器、
   关掉后再把向导恢复出来（视觉上是单层，但要处理向导草稿状态）？
3. **移动端**：两栏压成单栏（左栏折叠）够不够，还是降级成「先选考试 → 再编辑科目」两步？
4. **高度**：固定 `92vh`（内容少时下部留白），还是内容自适应（最多 92vh）？

## 附：另一件小事（可选，与上面独立）

左栏里单个科目的编辑表单（`编辑分考试 / 添加分考试`，`MajorTabPanel.tsx:308-442`）目前是**行内卡片**，
而周测侧同类表单早就是弹窗（`weekly/ItemFormModal`）。如果这次要把编辑器整体弹窗化，
建议顺手把这个卡片也改成弹窗——同一个容器里两层卡片太挤。要单独做的话，
它自己的方案是「单屏三段式（科目 / 时间 / 适用范围）+ 底部确认并保存」。
