## 命令与环境

从仓库根目录运行，使用 Node.js 24.x。

```powershell
# 普通代码改动
npm run verify:fast

# 发布/推送前
npm run verify:full
npx tsc -p tsconfig.json --noEmit
npm run serve:build
```

`verify:full` 当前只包含单元测试、Vite build、API typecheck；前端类型检查、服务构建、集成测试需要单独执行，CI 配置见 `.github/workflows/verify.yml`。

真实数据库测试会清空目标库。先准备独立可丢弃数据库，确认 `INTEGRATION_DATABASE_URL` 与业务 `DATABASE_URL` 不同，再设置 `INTEGRATION_TEST_CONFIRM=novora-disposable` 并运行 `npm run test:integration`。本机密码从本地秘密文件读取，不抄入本表；无需连接数据库的文档任务不读取密码。

Windows 构建、C# 测试、UI 和备份 smoke 的完整命令与参数见 [Windows README](../../packaging/windows/README.md#verification)。UI smoke 需要交互桌面；备份 smoke 使用独立临时 PostgreSQL 集群。构建成功不等于完成干净安装验收。

纯文档只检查本次文件的 Prettier、相对链接和 `git diff --check`。不要运行全仓 `format`，也不要因为共享工作树有其它改动而替它们标记验证成功。
