# Novora v2.8.4 更新日志

本版本加入全量备份与恢复能力，并按部署平台提供相应的文件管理方式。

## 备份与恢复

- **全量备份**：备份学校数据、考试、公告、设备绑定与账号，排除部署密钥和运行队列。
- **恢复前校验**：选择备份后先校验格式、数据库结构、完整数据列、管理员账号、内部校验和 SHA-256，再展示备份包含的业务内容，确认后才恢复。
- **恢复保护**：Linux 自部署在恢复前自动保存保护备份；Vercel 在恢复前生成并即时下载保护备份，服务端校验其签名后才覆盖数据。
- **校验文件**：可下载备份同时生成 `.sha256` 校验文件，下载完成后服务端确认分块完整并清理临时数据。

## 平台行为

- **Linux 自部署**：备份保存到配置的本地持久目录，支持手动备份、每日自动备份、保留份数、历史下载和恢复。
- **Vercel**：备份生成后即时下载文件和校验文件；云端保留生成时间、大小、状态与校验值等记录，不提供历史文件再次下载，也不做持久备份存储。
- **Windows**：设置页提供已有 `.dump` 文件的查看、下载和校验文件；备份、自动任务与恢复继续使用 Windows 控制中心 → 数据备份。

## 升级说明

- 备份相关表会由服务端按需创建或补充字段，不需要手工执行数据库迁移。
- 升级前仍建议先保留现有数据库备份；Vercel 的备份文件需要在生成时下载并自行保存。
