# Novora v2.8.2 更新日志

本版本基于 v2.8.1，重点是启用 Windows 签名更新通道，并收口安装、初始化、备份恢复、服务日志和控制中心的审计问题。

## 新功能与改进

- **Windows 在线更新通道**：完整安装包开始随附 `updater/trust.json` 公钥，控制中心通过 `update.pikachu2026.space` 获取作者端推荐，网络异常时回退可信 GitHub 稳定发布；清单、签名、包摘要和版本均需校验，离线 `.nvu` 导入同样验签。
- **更新安全边界**：作者端不可达、超时或返回 408/429/5xx 时才启用 GitHub 兜底；无推荐、409、清单或签名校验失败不会切换来源。下载支持续传，安装前执行保护备份，健康检查失败自动回退上一版本。
- **托盘菜单**：改用主题卡片样式，图标使用 GDI+ 绘制，修复白底、模糊和深色彩边，适配系统主题与高对比度。
- **Windows 安装与初始化**：安装器只负责文件、运行库和快捷方式；数据库初始化、服务注册和健康检查在初始化向导中完成。长时间运行的界面保持在普通权限，需要管理员权限的步骤单独提权。
- **初始化结果分级**：只有致命错误才使初始化失败；非致命警告照常显示并写入记录，不再关闭后续更新入口。产品版本统一从安装目录读取，避免脚本内硬编码。
- **备份、恢复与更新互斥**：备份、恢复、卸载和更新共用数据库维护锁；未完成更新阶段会阻止业务服务自行启动，但更新器自身的校验和回退阶段保持可启动。
- **服务日志**：多个输出流改为单写线程排队写入，按大小轮转并保留历史文件，避免并发写同一文件导致日志丢失。
- **系统检查页**：改为定向查询防火墙规则和计划任务，耗时不再随机器规则数量增长；检查超时从 20 秒提高到 45 秒，兜住冷启动。
- **控制中心单实例**：第二个实例通过本机管道把页面请求转交给已运行实例；管道暂时不可用时按退避重试，不再静默无响应。
- **控制中心诊断日志**：启动、单实例转发、监听失败和未处理异常写入 `%LOCALAPPDATA%\Novora\logs\controlcenter-*.log`，按 2 MiB 轮转并保留 3 份历史，Release 下“双击没反应”不再没有任何痕迹。
- **公告图片代理边界**：`/api/announcement-images` 的上游请求增加 10 秒超时，只接受 `image/*` 响应，单张图片上限 10 MiB，超时返回 504、类型或大小异常返回 502。
- **卸载失败上报**：卸载脚本把失败原因写入进度记录，安装器据此向操作员显示具体错误，而不是只显示“卸载失败”。
- **ClassIsland 条件同步**：插件可带 `knownVersion` 轮询，考试修订、年级/班级、绑定浏览器与中国日历日期都没变时返回 `changed=false` 并省略考试数据，稳定状态退化成一次 JOIN 小查询，不再反复下发大 JSON；`includeCompletedToday=true` 保留当天已结束的考试，让上午/下午整段考试模式能覆盖场间。capability 增加 `conditional-sync` 与 `session-history`，不带新字段的旧客户端协议不变。
- **公告代理去重**：`/api/announcements` 增加 60 秒进程内缓存并合并并发回源，不同 `limit` 共用一次最多 50 条的上游请求，发布/撤下窗口仍在代理侧逐次过滤；缓存以上游地址为键，作者端换公告域名立即生效。详见 `docs/CLASSISLAND-0.3.md`。

## 问题修复

- **局域网 http 登录被拦**：跨源判定改为比较请求主机，用 `http://内网地址` 访问本机服务时不再返回 403；非同源请求仍按白名单校验，https 与公网行为不变。Linux 与 Windows 同一份服务端代码，行为一致。
- **打开管理端无响应**：控制中心在提权或非交互令牌下没有默认浏览器关联，原来会报“找不到应用程序”；现在回退到通过 App Paths 找到的 Edge/Chrome 后再提示。
- **教室端时间显示**：快照选择与公告格式化改为按 `Asia/Shanghai` 解析和显示，设备时区不是中国时区时不再把 09:10 显示成 01:10。
- **批量添加跨天考试**：日期键改用 UTC 锚点计算，UTC+8 下“次日结束”不再被算回当天，跨天考试可以正常通过校验。
- **设备离线提示**：服务端“最后在线”统一按上海时区显示，UTC 部署不再比北京时间少 8 小时。
- **服务端请求边界**：畸形 URL 返回 400，非法 JSON 请求体返回 400，超过 2 MiB 的请求体返回 413，不再统一落成 500。
- **设备在线状态**：ClassIsland 插件在线状态改为读取 `pluginLastSeenAt`，修复心跳正常却一直显示离线的问题。
- **运行日志凭据**：设备日志通道继续使用本机设备密钥，不读取管理员会话令牌；鉴权头收敛到 `auth/session.ts` 的 `deviceAuthHeaders(secret)`，业务文件里不再手拼 `Bearer`。静态检查随之改为断言客户端走该封装、且封装只认调用方传入的 secret，不回落到会话令牌。
- **考试启动器**：移除重复的 `getAppSettings` 导入。
- **运行日志分页**：使用兼容旧运行时的数组下标写法，避免 `Array.prototype.at` 在旧环境不可用。

## 升级说明

- **2.8.1 及更早版本没有更新公钥，不能通过在线更新升级到 2.8.2。** 需要手工安装一次 `Novora-Setup-2.8.2.exe` 完整包；此后才可通过控制中心接收在线应用更新。
- 安装 2.8.2 完整包后，`updater/trust.json` 会随包部署；应用更新不会覆盖学校配置、数据库、日志或备份。
- 本版本应用更新要求 Node 24、Windows x64，数据库迁移保持向后兼容。首个生产签名发布需同时上传签名清单、签名、应用包和完整安装包。
- 作者端不可达时可使用离线 `.nvu` 包导入；导入前同样校验签名和摘要。
