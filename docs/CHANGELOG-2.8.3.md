# Novora v2.8.3 更新日志

本版本修复后台更新考试信息后教室端偶发不刷新的问题，覆盖后台考试快照变更及同一设备在管理页和教室页之间切换的场景。

## 同步改进

- **后台改动统一推进快照版本**：考试与班级数据保存、考试记录生命周期动作、自动开考/结束转换、设计规则、批量预设和数据库重置都写入严格递增的 `exam_data.updated_at`，并在响应中返回实际落库版本。
- **心跳广播当前版本**：所有部署的设备心跳都返回当前考试快照版本；只有明确支持版本化边缘缓存的部署才启用相应缓存路径。考试版本与独立的全局校时 revision 不混用。
- **后台写入主动通知**：保存成功后通知当前标签页并通过同源存储信号通知其他标签页；教室端收到变化后强制拉取最新完整快照。
- **切回教室端主动核对**：页面重新可见、窗口重新聚焦、`pageshow` 和网络恢复时强制刷新，避免同一设备在后台修改后切回时继续展示旧考试时间或配置。
- **强制刷新避免旧响应回写**：新鲜读取绕过 ETag、部分快照和浏览器缓存；它会等待先前条件请求结束，并与并发普通读取合并，避免较早的响应覆盖新快照。
- **保留离线编辑保护**：存在待同步 outbox 时仍不以服务器快照覆盖本地待办；已加入快照单飞、强制刷新、跨标签页通知和心跳传输回归测试。

## 界面优化

- **考试详情按任务优先级收拢**：考试详情固定在顶部常驻展示，科目与设备合并为无间隙的连续面板，生命周期移到底部整行；公告管理提升为独立入口，更多菜单只保留单个低频操作。已结束科目与操作记录按需展开，操作记录使用独立滚动区域，并统一标题、区块、正文与辅助文字的字号层级。
- **操作区随状态收敛**：保留快捷延长单科考试入口，延长改为浮层设置，备注按需显示；修正宽屏下详情内容堆在左半栏的问题，并补充科目切换、详情展开、设备明细与浮层出现的克制动效。

## 升级说明

- 从 2.8.2 升级到 2.8.3 不需要数据库迁移；快照版本仍使用现有 `exam_data.updated_at` 字段。
- 本次修复覆盖后台快照写路径和教室端重新激活读取逻辑。发布前检查结果以本次构建记录为准；该日志不宣称尚未执行的集成库、完整验证或 Windows 目标机验收已通过。
