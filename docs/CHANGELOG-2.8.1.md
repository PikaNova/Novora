# Novora v2.8.1 更新日志

本版本基于 v2.8.0，重点改进考试调度、教室端时间与数据同步，并新增运行日志和平台用量监控。

## 新功能与改进

- **Windows 更新页展示**：重排版本与通道状态、在线三步流程、离线导入、记录与缓存、匿名统计；按当前阶段显示下载与安装操作，校验、兼容限制和失败结果提供明确反馈，缓存清理先确认。
- **Windows 安装与运维反馈**：安装、初始化、服务启停和备份恢复显示当前项目、真实进度或等待状态；失败保留详细结果并提供日志、诊断与重试入口。托盘适配系统主题、高对比和 DPI，区分服务状态与 HTTP 健康。
- **Windows 软件更新**：设置页接入独立签名更新与离线导入、保护备份、版本切换和恢复代码。作者端优先推荐，仅网络故障、超时及 HTTP 408/429/5xx 时回退 GitHub；无推荐或验签失败不会回退。匿名更新统计默认关闭，发送失败不影响业务。生产更新通道仍需发行配置与发布资产，见 [更新说明](../packaging/windows/UPDATES.md)。

- **考试调度规则**：系统设置新增全局运行模式，可选择自动调度、仅大型考试或仅周测；可配置大型考试与周测的冲突处理范围，以及时间重叠时的开考前后缓冲时间。
- **大型考试期间锁定创建**：可按学校需要，在大型考试期间暂停新建周测和临时考试；已有计划仍可查看，大型考试结束后自动恢复创建。
- **当前考试看板**：重整当前考试页面，集中查看上一场、正在进行和下一场考试，以及倒计时、设备在线和数据同步状态。
- **云平台用量监控**：设置页可查看 Vercel 与 Neon 用量，追踪历史趋势和免费额度预计可用时间；支持调整额度上限和补充手工记录的指标。平台凭据保存在服务端，不写入环境变量或浏览器。
- **教室运行日志**：教室端记录经脱敏的显示、校时、同步、设备指令、公告、网络、页面、PWA 和本地存储事件，并自动上传到学校后台。管理员可查看趋势与设备状态，按时间、设备和事件类型筛选，并导出日志。
- **诊断日志预览**：发送详细诊断日志前，可先确认时间范围和日志条数，再决定是否上报；日志发送前会过滤敏感信息。
- **全校时间控制**：管理员可设置全校统一时间偏移，并向教室客户端下发校时任务、查看成功/失败/待响应数量。客户端的时钟、倒计时和提醒共享校准时间基准。
- **考试变更通知**：大型考试安排发生更新时，教室端会收到提示并及时同步最新安排；周测的创建限制与大型考试冲突规则保持一致。
- **公告回执与状态提示**：优化学校公告送达、已读回执的展示；公告读取失败时明确提示错误，避免看起来像空列表。

## 问题修复

- **ClassIsland 在线状态**：设备管理按接口返回的 `pluginLastSeenAt` 解析插件心跳，修复插件正常同步却始终显示离线的问题。

- **Windows 安装与初始化分离**：安装器仅准备基础文件、运行库与快捷方式，数据库集群创建和两服务注册迁至初始化，不再直接执行 PostgreSQL 配置探测、启动服务或等待健康检查。初始化通过服务账户启动数据库，验证真实连接并准备业务库，再启动业务服务和验证 HTTP；失败保留具体项目并可重试。兼容的新版 VC++ 运行库直接跳过安装。保留 PostgreSQL 配置 BOM 修复及维护互斥保护。

- **考试历史与搜索**：修复跨月考试被拆分归组；搜索增加防抖，并在接口限流后正确重试，减少搜索失败或重复请求。
- **考试状态显示**：修复考试暂停、结束、归档或调整时间后，考试安排状态胶囊未及时同步的问题。
- **考试设置操作**：关闭设置面板时，如果没有待保存的草稿，不再错误弹出草稿提示。
- **教室校时**：修复校时数据过期或网络失败时错误退回设备本机时间的问题；避免缓存时间响应和过期跨窗口消息覆盖当前校准，并让时钟、倒计时和提醒共享同一时间基准。
- **平台用量数据**：修复 Vercel 用量接口参数及响应格式识别；避免将不匹配的额度套用到指标上导致百分比误导。Neon 免费版无法读取的指标不再显示为 0。
- **创建限制**：修复大型考试期间周测创建锁在部分入口未生效，以及锁定检查读取范围和 ID 类型不一致的问题。
- **公告与管理界面**：公告读取失败时显示错误提示；修复管理页 Hook 顺序导致的渲染问题、移动端班级管理标题可读性，以及用量面板自定义指标行溢出卡片的问题。

## 升级说明

运行日志数据表会在首次使用相关功能时自动创建，无需手工执行 SQL。其余功能沿用现有数据结构和部署流程；更新后按部署方式刷新应用与客户端缓存即可。

- **Windows 初始化兼容修复**：修复 Windows PowerShell 5.1 下旧初始化记录和端口配置原子替换时报路径格式错误；新增实际文件替换回归验证，失败日志记录脱敏调用位置。
