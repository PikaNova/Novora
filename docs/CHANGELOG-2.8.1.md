# Novora v2.8.1 更新日志

- 修复设备管理读取插件心跳字段错误，导致 ClassIsland 正常同步却显示离线的问题。
- 修复教室时钟在网络校时过期或失败时退回本机时间的问题。
- 页面内统一单调时钟服务，时钟、倒计时与考试提醒共享时间来源。
- 校时写入限制在教室页面，通过跨窗口租约与 Web Locks 协调；传递带版本号的服务器时间，拒绝旧校时消息。
- 不再持久化跨页面无效的单调时钟锚点，兼容清理旧字段。
- 移除首页备用校时，校时请求绕过 Service Worker 缓存；异常样本及大幅时间变化需要确认。
- 补充校时来源、窗口、版本、偏差、失败与过期诊断日志。
- 更新应用、PWA 缓存及 Windows 启动器版本为 2.8.1。
