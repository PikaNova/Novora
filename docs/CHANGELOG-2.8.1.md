# Novora v2.8.1 更新日志

本版本基于 v2.8.0，改进考试调度、教室端时间与数据同步，并增加运行日志和平台用量监控。

## 新功能与改进

- **考试调度规则**：系统设置新增全局运行模式，可选择自动调度、仅大型考试或仅周测；可配置大型考试与周测的冲突处理范围，以及时间重叠时的开考前后缓冲时间。
- **大型考试期间锁定创建**：可按学校需要，在大型考试期间暂停新建周测和临时考试；已有安排仍可查看，大型考试结束后自动恢复创建。
- **当前考试看板**：重整当前考试页面，集中查看上一场、正在进行和下一场考试，以及倒计时、设备在线和数据同步状态。
- **云平台用量监控**：设置页可查看 Vercel 与 Neon 用量、历史趋势和额度预计可用时间；支持调整额度上限和补充手工记录的指标。
- **教室运行日志**：教室端记录经过脱敏的显示、校时、同步、设备指令、公告、网络、页面、PWA 和本地存储事件。管理员可查看趋势与设备状态、筛选并导出日志；已登记且未撤销的教室设备会自动上报。
- **诊断日志预览**：发送详细诊断日志前，可确认时间范围和日志条数，再决定是否上报。
- **全校时间控制**：管理员可设置全校统一时间偏移，并向教室客户端下发校时任务、查看成功/失败/待响应数量。客户端的时钟、倒计时和提醒共享校准时间基准。
- **考试变更通知**：大型考试安排更新时，教室端会收到提示并及时同步最新内容。
- **公告与状态提示**：优化学校公告送达和已读回执；公告读取失败时明确提示错误。

## 问题修复

- 修复考试历史跨月分组、搜索防抖和限流重试问题。
- 修复考试暂停、结束、归档或调整时间后状态没有及时更新的问题。
- 修复校时数据过期或网络失败时退回设备本机时间的问题，并避免缓存或过期跨窗口消息覆盖有效校准。
- 修复平台用量接口数据识别问题，避免显示误导性的额度百分比；无法读取的指标会明确标示。
- 修复大型考试期间创建限制在部分入口未生效的问题，并改善公告读取失败提示及管理界面的若干布局问题。

## 升级说明

运行日志数据表会在首次使用相关功能时自动创建，无需手工执行 SQL。其他功能沿用现有数据结构和部署流程；更新后请按部署方式重新部署并刷新应用缓存。
