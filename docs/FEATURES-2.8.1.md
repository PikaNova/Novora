# Novora v2.8.1 新功能介绍

Novora v2.8.1 让考试安排更可控，也让学校管理员更容易掌握教室设备和部署服务的运行情况。

## 考试安排更灵活

在“系统设置 → 考试与排课”中，管理员可以统一选择自动调度、仅大型考试或仅周测，并设置大型考试与周测发生冲突时的处理范围。开启大型考试期间的创建锁定后，系统会暂时禁止新建周测和临时考试，已有安排仍可查看，考试结束后自动恢复。

“当前考试”看板集中展示上一场、当前和下一场考试。考试安排发生变化时，教室端会收到提示并同步最新内容，减少管理端和大屏信息不一致的情况。

## 运行情况一目了然

新增“运行日志”面板，用于查看教室设备和服务端的运行事件。管理员可以按时间、设备、事件类别和级别筛选，查看设备在线状态与事件趋势，并导出日志供排查使用。教室日志会自动汇总上传，内容经过敏感信息过滤。

“诊断日志”增加发送前预览。选择时间范围后，先查看待发送日志数量，再确认是否上报，便于掌握本次提交的范围。

## 提前掌握平台额度

平台用量面板汇总 Vercel 和 Neon 的资源使用情况，并根据历史用量估算额度剩余时间。管理员可调整额度上限，也可添加平台接口未提供的自定义指标。没有足够历史样本时，面板会说明暂时无法预测。

## 校准全校时间

管理员可以在时间同步设置中配置全校统一偏移，并一键下发客户端校时任务。操作后可查看成功、失败、待响应设备数量；教室端的时钟、考试倒计时和提醒使用统一的校准时间基准。
